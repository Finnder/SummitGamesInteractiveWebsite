# Game Jam Collection

**Status:** Released · **Price:** Free

Before Summit Games Interactive was a studio, it was a group of friends entering game jams. This is a collection of our favorite jam entries — rough edges and all.

## Included games

- **Peak Panic** — a 48-hour climbing game where the mountain fights back
- **Snowed In** — a tiny narrative game about being stuck in a cabin with a mystery
- **Yeti Tycoon** — run a gift shop for cryptids; made in 72 hours, somehow works

## Where to play

Links to each game will live here (itch.io embeds work great with GitHub Pages). For now, ask us on the [contact page](contact.html) and we'll send you a build.
